AVM, Accessible Virtual Machine: third-party notices
====================================================

AVM is free software under the GNU General Public License, version 2
(the LICENSE file at the root of its repository,
https://github.com/allisonfm85/accessible-virtual-machine). So that
it runs with nothing else installed, it bundles the programs, libraries,
drivers and installers below, built or copied from the sources named
here. Each keeps its own licence. The licence texts are in this folder,
Resources/Licenses inside the app, one folder per package, and
INDEX.txt there lists what was collected and from which version. In AVM,
Help > Open Source Licenses opens the folder.

Written 2026-10-29 (seventh audit). Tools/build-sysroot.sh collects the
texts; keep this file in step with it and with Resources/virtio and
Resources/vdagent.


Source code: the offer
----------------------

Every component below under the GNU General Public License or the GNU
Lesser General Public License, in any version, comes with this offer.
The complete corresponding source is the pinned source tarball named in
Tools/build-sysroot.sh (and checked against Tools/sysroot-sources.sha256
when it is downloaded), or the git commit named there or below, plus
the patches in Tools/sysroot-patches, which are the only changes AVM
makes. For the Windows installers it is the upstream release named

Built from source into the app (the sysroot)
--------------------------------------------

Tools/build-sysroot.sh runs UTM's dependency build (Turing Software,
https://github.com/utmapp/UTM, Apache License 2.0) at a pinned commit.
It downloads the tarballs below, applies UTM's patches and then AVM's,
and builds them. The Xcode project's Run Script phase stages the result
into the app: every library in the sysroot's lib folder goes into
Contents/Resources, and every framework but QEMU's into
Contents/Frameworks, so a few libraries AVM itself never calls are in
the app too. They are listed with the rest. UTM's patches to the GPL and
LGPL packages are under those packages' licences.
